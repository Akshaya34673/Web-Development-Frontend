STEP 1: Login to AWS Academy Account

Open your course invitation email → Click Start.

AWS Academy opens → Choose Student Login → Enter email & password.

Click Modules.

Scroll down → Select Launch AWS Academy Lab.

Click Start Lab → Wait until the AWS icon turns green.

Click AWS to open the console.

STEP 2: Create an EC2 Instance

Search for EC2 in the AWS console.

Click Launch Instance.

Stage 1: Name

Give a name: ubuntu

Stage 2: Select AMI

Choose Ubuntu Server (Free tier eligible).

Stage 3: Architecture

Select 64-bit.

Stage 4: Instance Type

Choose t2.micro (1 CPU, 1 GB RAM).

Stage 5: Create Key Pair

Click Create new key pair.

Give a name (e.g., aws-key).

Download the .pem file.

Save it in an “AWS” folder on your Desktop.

Stage 6: Network Settings

Create a new security group.

Enable the following:

HTTP (port 80)

HTTPS (port 443)

SSH (port 22)

Check all required checkboxes.

Stage 7: Storage

Use default 8 GB.

Stage 8: Launch

Click Launch Instance.

Go to Instances → Wait for 2/2 checks passed.

Select your instance → Click Connect.

STEP 3: Connect Your Local System to the EC2 Server via SSH
a. Copy the path of your .pem file

Example:
C:\Users\aksha\Documents\AWS

b. Open PowerShell as Administrator

Navigate to the .pem path:

cd C:\Users\aksha\Documents\AWS

c. In AWS → EC2 → Connect → SSH Client

Copy the SSH command (example):

ssh -i "aws-key.pem" ubuntu@ec2-xx-xx-xx-xx.compute.amazonaws.com

d. Paste SSH command in PowerShell and connect
STEP 4: Install Required Software in EC2

Run these commands one by one:

1. Update all software
sudo apt update

2. Install Docker
sudo apt-get install docker.io

3. Install Git
sudo apt install git

4. Install Nano editor
sudo apt install nano

STEP 5: Create and Push Your Application to GitHub
a. Create index.html file

Make a folder named Example.

Create a basic index.html file inside it.

b. Open Git Bash inside the Example folder

Right-click → Git Bash Here

c. Run Git commands
git init
git add .
git commit -m "first commit"

d. Create a GitHub Repository

Name it AWS.

e. Run GitHub commands

Copy from GitHub and run:

git branch -M main
git remote add origin <your GitHub repo link>
git push -u origin main

f. Refresh GitHub

You should see index.html in your repo.

STEP 6: Clone the Repo Inside EC2
a. Copy the HTTPS URL from GitHub
b. Run:
git clone <your repo URL>
cd AWS
ls

STEP 7: Create a Dockerfile in EC2
a. Create file
nano Dockerfile

b. Write this content inside:
FROM nginx:latest
COPY . /usr/share/nginx/html

c. Save

CTRL + O → ENTER

CTRL + X

STEP 8: Build the Docker Image
sudo docker build -t mywebapp .

STEP 9: Run the Docker Container (Expose Port 80)
sudo docker run -d -p 80:80 mywebapp

STEP 10: View Your Website

Go to EC2 → Instances.

Copy Public IPv4 address.

Paste it in browser:

http://<public-ip>


Your index.html should display.

STEP 11: Stop and Terminate the Instance
a. Stop container
sudo docker ps
sudo docker stop <container-id>

b. Terminate instance

EC2 → Instances → Select → Instance State → Terminate

c. End Lab
EXERCISE 2: Maven Web Project Deployment on AWS

(The steps are similar, only repo and Dockerfile change.)

STEP 1: Launch Lab

Start the AWS Academy lab.

STEP 2: Create EC2 Instance

Same steps as previous (Ubuntu, t2.micro, key pair, network settings).

STEP 3: Connect via SSH

Use SSH command.

STEP 4: Install Required Software

Same as before:

sudo apt update
sudo apt-get install docker.io
sudo apt install git

STEP 5: Clone Maven Web Project

Open GitHub.

Copy your Maven project HTTPS link.

Run:

git clone <url>
cd <project-folder>


If branch is not main, change GitHub default branch.

STEP 6: Build Docker Image
sudo docker build -t mavenwebapp .

STEP 7: Run Container

(Example uses port 9090)

sudo docker run -d -p 9090:9090 mavenwebapp

STEP 8: Open in Browser

Paste:

http://<public-ip>:9090


If it doesn’t load:

Enable inbound rule

EC2 → Security Groups.

Edit inbound rules.

Add rule:

Custom TCP

Port: 9090

Source: 0.0.0.0/0

Save.

Refresh the browser → App loads.

STEP 9: Stop & Terminate
sudo docker ps
sudo docker stop <container-id>


Terminate instance.

End Lab.
